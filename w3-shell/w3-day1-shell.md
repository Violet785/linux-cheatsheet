## 踩坑清单（本人实录，关键项已进错题本）

1. **命令行 ≠ 编辑器**：把 `#!/bin/bash` 直接敲在提示符后（只是注释）；`echo "hello" > hello.sh` 只写入一行 `hello`，运行时 `hello: 未找到命令`。脚本要用 nano / VSCode / heredoc 写进文件。
2. **路径空格**：`cd ~/shell -lab` → `参数太多`，空格把路径劈成了两个参数。
3. **拼写**：`chome` / `chomd` → `chmod`；`data` → `date`；`df -p` → `df -P`（实测报无效选项）；`tail -i` → `tail -1`。
4. **符号混用**：`if [ ... };` 用 `}` 收尾、`$[DISK_USED}` 写成 `$[`；`bash -n` 报错行号可能滞后（报第 9 行，病根在第 7 行），要往上找。
5. **静默错误**：变量为空时 `$(( ))` 当 0 算，不报错；`[ "8%" -ge 80 ]` → `需要整数表达式`，退出码 2。`if` 把非 0 一律当假，容易走错分支——先把中间值 `echo` 出来再判断。

## 自测结论

- 退出码：0 = 成功/真；1 = 判断为假；2 = 表达式错误。
- `[` 是命令（test），所以 `[` 后、`]` 前必须有空格，`]` 不可省。
- `$()` 只捕获 stdout；错误信息走 stderr，屏幕能看见、变量里没有。
